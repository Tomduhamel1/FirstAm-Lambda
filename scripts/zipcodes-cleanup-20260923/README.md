# ZipCodes placeholder cleanup (2026-09-23)

`scripts/complete-remaining-6-states.js` (Feb 2026) filled every unused 5-digit number in the
NH/ME/FL/CO/TN/TX zip ranges with `"XX City"` / `"XX County"` placeholders. 8,893 such rows were
found (`placeholders_full.tsv`). Sent to FirstAm they produce blank L2 questions (`RFC__0`) and
"Invalid Property Location" (file 294021, zip 34430).

- `fix_clean.tsv`: 1,463 placeholders that are real USPS zips (source: GeoNames US postal codes,
  CC BY 4.0) -> overwritten with real city / county / state. Counties use the table's "St. X" form.
- `delete_clean.txt`: 7,430 numbers that are not real zips (plus 38 military APO/FPO) -> deleted,
  so unknown zips return the API's 404 "Zip code not found" instead of garbage going to FirstAm.
- `batches/`: 356 `batch-write-item` request files (25 per file), generated by `gen_batches.js`.
- `run_cleanup.sh`: raises write capacity 1 -> 25, applies the batches with retries, restores 1.
  Re-runnable. Log in `cleanup.log` next to the script.
